# 시관 (sigwan)

시간 관리 앱. 설계 명세는 프로젝트 문서 `claude/설계명세.md` 참조.

현재 단계: **M1 — 웹 프로토타입 (로컬 저장만)**

```
packages/core   타입 · 점수 함수 · 타임라인 좌표계 · Repository 인터페이스 · 목 데이터
apps/web        React + Vite 웹 클라이언트 (Dexie 로컬 저장)
```

## 시작

```bash
corepack enable && corepack prepare pnpm@latest --activate
nvm use            # .nvmrc = 24
pnpm install
pnpm test          # 명세 4장 검산표 5줄이 첫 테스트다
pnpm dev           # http://localhost:5173
```

첫 실행 때 목 데이터(Task 50 / Block 30 / 태그 8)가 자동으로 들어간다.
화면 오른쪽 아래 "목 데이터 리셋"으로 다시 넣을 수 있다.

## 지금 되는 것

- 급한 순 정렬 (명세 4장 점수 공식, 등급색 스트라이프)
- 줌 4단계 — `1`~`4` 키, `T`로 오늘, `◀ ▶`로 이동
  - 일 = 세로 열 1개 · 주 = 월~일 세로 열 7개 (둘 다 드래그 편집, 옆 열로 끌면 날짜 이동)
  - 월 = 달력 격자 (마감 칩·블록 수, 드롭하면 09:00 블록) · 분기 = 미니 달력 3장
- 블록 드래그 이동 · 아래끝 드래그로 길이 조절 (15분 스냅, `Alt`로 해제)
- 할 일 리스트 → 타임라인 드롭으로 블록 생성. 막대를 누르면 그 할 일이 열린다
- **할 일 추가 폼 (3.3)** — `N` 또는 「+ 할 일」. kind는 입력이 결정하고,
  저장 전에 등급·점수·급한 순 순위를 보여준다
- **상세에서 마감·예상·중요도·태그 편집** — 마감을 고치면 kind가 따라 바뀐다
- **태그 추가·이름/색 변경·삭제** (사이드바 태그 머리의 `+` / `✎`)
- 패널 비율 드래그 (사이드바↔가운데, 간트↔리스트). localStorage에 기억
- 상세 배치 두 가지 — 오른쪽 패널 / 리스트 인라인 펼침. 헤더 버튼으로 전환

## 아직 안 되는 것 (M1 남은 분량)

- 한 줄 입력 파서 (`#학교 !5 6h @16:30`) — 웹 전용, M5여도 된다
- 하위작업 progress 자동 계산, 반복(RRULE)
- 백엔드 일체 — M2. `packages/core/src/repo.ts` 인터페이스만 지키면 갈아끼운다

## 규칙 두 개만

1. **점수·좌표 계산을 화면 코드에서 직접 하지 않는다.** `@sigwan/core`의 함수만 쓴다.
   웹·앱·위젯 세 곳이 같은 함수를 봐야 정렬이 안 어긋난다.
2. **`user_id` 조건을 화면 코드에 쓰지 않는다.** Repository 계층이 주입한다 (명세 10.1).
